# BlockWorld 4

Minecraft-ის მსგავსი, მაგრამ ორიგინალური 3D multiplayer თამაში 4 მეგობრისთვის.

## ლოკალურად გაშვება

```bash
npm install
npm start
```

შემდეგ გახსენი:

http://localhost:3000

## ონლაინ

GitHub Pages მხოლოდ `index.html`-ს ვერ გაუშვებს WebSocket server-თან ერთად. `server.js` განათავსე Render/Railway/Fly.io-ს მსგავს Node.js hosting-ზე და `index.html`-ში WebSocket მისამართი შეცვალე შენი server URL-ით.

## controls

WASD — მოძრაობა
Mouse — კამერა
Left click — ბლოკის მოტეხვა
Right click — ბლოკის დადება
1-5 — ბლოკის არჩევა
ESC — mouse-ის გათავისუფლება
